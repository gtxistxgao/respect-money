Get started locallyTerminal
# Clone the project
git clone https://github.com/gtxistxgao/respect-money.git
cd respect-money

# Install and start
npm ci
npm run dev

Then open localhost:5173 in your browser.

A few things to know.

Do I need to connect a bank?

No. You can create a manual account and start recording transactions immediately. Bank sync is optional and requires your own Plaid configuration; availability depends on your Plaid access and supported institutions.

Does everything work offline?

Manual bookkeeping uses your local database. Bank sync connects to Plaid, and AI classification uses your signed-in Codex model service. AI processing is not fully offline.

What does the ledger track?

Income and spending totals cover posted USD transactions, including cash dividends, interest, and standalone investment fees. Transfers, credit card repayments, and securities trades stay out of those totals. Portfolio profit and loss is not included.

Is this a hosted finance app?

No. This page introduces the project. The application runs on your computer for a single local user; it is not designed for public internet hosting.
